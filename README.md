# make-knowledge-cards

## 项目解决什么问题

阅读文章后，手动整理复习笔记容易遗漏重点、重复记录，或把多个概念混在一起。本项目提供一个供支持 Skill 的 AI 工具加载的技能，将原文提炼为便于理解和自测的 Markdown 知识卡片。

## 主要功能

- 接收粘贴的文章，以及本地 `.md`、`.markdown`、`.txt` 文件；可合并多份材料并保留来源。
- 通常生成 5～8 张卡片，一张只讲一个知识点，合并重复内容，优先保留重要知识。
- 每张包含标题、核心知识、简明解释，以及原文例子或自测问题；自测题附参考答案，卡片附来源定位。
- 只使用原文支持的信息，保留适用条件、不确定性和作者观点归属，不补写事实或例子。
- 信息不足时少于 5 张并说明原因；没有可提取知识时不生成卡片。
- 默认在对话中输出 Markdown，用户要求保存时才写文件。

暂不支持网页抓取、PDF、Anki 和图形界面。此项目包含技能指令与界面元数据，不提供独立运行的转换程序；生成质量取决于执行技能的模型，重要内容仍需对照原文核查。

## 安装方法

1. 准备支持加载 `SKILL.md` 的 AI 工具；处理本地文件时，该工具还需要能够读取对应文件。
2. 下载本项目，将 `skills/make-knowledge-cards` 整个目录复制到该工具支持的技能目录，具体目录以所用工具的说明为准。保留以下结构：

   ```text
   make-knowledge-cards/
   ├── SKILL.md
   └── agents/
       └── openai.yaml
   ```

3. 按所用工具的方式加载或刷新技能，然后在会话中调用 `make-knowledge-cards`。支持本地技能路径的工具也可以直接加载本项目中的技能目录。

本技能无需安装额外脚本或运行依赖。

## 使用方法

在支持 `$技能名` 调用的工具中，使用 `$make-knowledge-cards` 并附上正文或文件路径；其他工具按其技能调用方式使用。读取文件时建议提供完整路径。

```text
请使用 $make-knowledge-cards 整理本地文件 F:/notes/article.md。
```

如果需要保存结果，可明确指定输出文件：

```text
请使用 $make-knowledge-cards 整理本地文件 F:/notes/article.md，
将结果保存到 F:/notes/article-cards.md。
```

也可以直接粘贴正文，见下方示例。仅提供网页链接或 PDF 时，需要先自行准备正文或支持的文本文件。

## 输入输出示例

### 输入

```text
请使用 $make-knowledge-cards 整理下面的文章：
主动回忆是先不看材料，尝试从记忆中回答问题。
例如，合上书后回答“这一节讲了什么”。
```

也可以提供文件：`请使用 $make-knowledge-cards 整理本地文件 notes.md。`

### 输出

来源：粘贴正文。仅有一个独立知识点，因此生成 1 张卡片。

### 卡片 1：主动回忆
- **核心知识**：主动回忆是在不看材料时尝试从记忆中回答问题。
- **简明解释**：先移开材料，再凭记忆作答。
- **例子**：合上书后回答“这一节讲了什么”。
- **来源**：粘贴正文，第 1～2 段。

本地行为测试与结果见 [tests/RESULTS.md](tests/RESULTS.md)。
